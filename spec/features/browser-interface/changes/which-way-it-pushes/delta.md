# Delta — browser-interface

> The change expressed against the current spec as explicit operations.

## MODIFIED

- **AC-59.** Was: the overlay draws where the wind comes from, and every claim states that a
  direction is where the wind comes *from* and what that means for a fire, because the opposite
  reading inverts every conclusion. Now: the overlay draws which way the wind *pushes*, and no
  direction is ever shown to a reader the other way round. The old criterion asked the page to say
  a hard thing clearly and it did; the question that followed proved that saying it clearly is not
  the same as being read. So the drawing and the words both move, and the criterion holds them to
  each other rather than holding the words to the drawing.

  The meteorological direction is still what is fetched, parsed and stored: the criterion is about
  what a reader is shown, and the turn is a property of the page, not of the record.
