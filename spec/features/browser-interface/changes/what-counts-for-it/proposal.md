# Proposal — browser-interface

**Trigger:** "We have the Concerns column, but there isn't a column talking about the good stuff for
a property." The assessment feature is growing the other half of the question
(`property-assessment/changes/both-sides/`); this is the half of that work that belongs to the table.

**Summary:** A second column beside Concerns, drawn as the same control with a different icon, and a
second section in the dialog both of them open.

**The same control, not a different one.** The two counts are read together, in one movement: "two
things for it, three against" is the sentence a person assembles as their eye crosses the row. Two
differently shaped buttons would read as two unrelated facilities rather than as two halves of one
reading. So it is the same button, the same badge, the same three states and the same marks, and
only the icon differs: a tick rather than a magnifying glass.

**Not a star.** The first column of this table already uses a star, and it means *the person kept
this house*. Reusing it for a model's opinion would put the two most important things on the row
into the same symbol, and the boundary this feature keeps everywhere else is exactly that those two
must never be confused.

**Before Concerns, not after.** It is the order the questions get asked in, and a column of worries
read first colours the row behind it.

**One dialog, two sections.** Pressing either control opens the same assessment, because there is
one reading of the house and these are two sections of it. A person opened it to find out about a
property, not to choose which list to read.

**Blast radius, inside this feature.** AC-86 and AC-87 both gain the second half; nothing else in
either changes, and the arguments they already make (an ordinary declared column, out of the default
spreadsheet, in the opening view, conveying nothing by colour alone, and the person's own judgment
staying visibly theirs) apply to it unaltered. The declared-column count goes from forty-four to
forty-five and the default sheet stays at thirty-two, so feat-011's header is untouched again.
